| 类型 | 次数（约） |

**关键**：panic **都发生在关机/重启阶段**，不是运行中。
`Previous shutdown cause: 5` 每次开机都能看到。

### 用户态进程被 SIGKILL（流畅档专属）

开启 GPU 接管后：

| 进程 | 崩溃次数 |
|---|---|
| `SafariBookmarksSyncAgent` | 27 |
| `AuthenticationServicesAgent` | 25 |
| `assistantd` | 24 |
| `CommCenter` | 22 |
| `axassetsd` | 7 |
| `sharingd` | 6 |
| `com.apple.dock.extra` | 6 |
| `acountsd` | 5 |
| **`Safari`** | **5** |
| `siriactionsd` | 4 |

崩溃特征：

```
EXC_BAD_ACCESS / SIGKILL (Code Signature Invalid)
CODESIGNING / Invalid Page
栈：libobjc readClass → map_images → _objc_init（死在动态库加载阶段）
```

内核日志：

```
CODE SIGNING: cs_invalid_page(0x7ff82742f000): ... denying page sending SIGKILL
  ... rejecting invalid page ... in file ".../dyld/dyld_shared_cache_x86_64h"
```

**地址每次都一样** → 同一个被写脏的共享缓存页。
原因：`nullarc` 改写内存页，落在 `dyld_shared_cache` 里触发签名校验。

### SafeEjectGPUService 100% CPU

```
PID 1011  99.2%  .../SafeEjectGPUService.xpc/Contents/MacOS/SafeEjectGPUService
```

「安全弹出 GPU」菜单栏组件，卡在 GPU 驱动的 ioctl 里永不返回。
`kill -9` 无效（PID 不变，D state）。

完整分析见 [docs/07-稳定性与崩溃分析.md](../docs/07-稳定性与崩溃分析.md)。
