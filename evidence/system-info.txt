关键行解读：

| 行 | 含义 |
|---|---|
| `PhxAMDFB on the panel: 1` | M2 模式，PhxAMDFB 接管了面板 |
| `scratch0=0xdeadbeef (want deadbeef)` | **计算队列**写入/读回验证通过 |
| `scratch1=0xdeadbeef (want deadbeef)` | **图形队列**写入/读回验证通过 |
| `grbm=0xa800302c` | GRBM 状态寄存器非零 = CP 在跑 |
| `claim -> kr 0x0` | Metal 加速器认领成功 |
| `armed and released at ...; agdc 1` | 显示 arming 完成，AGDC 生效 |
| `frames on the panel 1129` | 面板上已合成 1129 帧 |
| `PhxAMDFB armed for the next boot` | arming 已持久化到 NVRAM |

| 指标 | 修复前 | `killall WallpaperAerialsExtension` 后 |

| `load average` | 4.66 | **3.14** |
